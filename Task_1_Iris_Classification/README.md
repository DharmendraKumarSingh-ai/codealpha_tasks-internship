# Task 1: Iris Flower Classification

## 📌 Project Overview

This project is part of my CodeAlpha Data Science Internship. The objective of this task is to build a Machine Learning model that can classify Iris flowers into different species based on their measurements.

## 🌸 Dataset

The Iris dataset contains 150 flower samples belonging to three species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

### Features

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

### Target

* Species

## 🛠️ Technologies & Libraries

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## 🤖 Machine Learning Model

A Decision Tree Classifier is used to train the model and classify the Iris flower species based on the given measurements.

## 🔄 Project Workflow

1. Load the Iris dataset
2. Explore the dataset
3. Check for missing values
4. Visualize the data
5. Separate features (X) and target (y)
6. Split the dataset into training and testing data
7. Train the Decision Tree model
8. Make predictions
9. Evaluate model performance
10. Visualize the Decision Tree
11. Predict the species of a new flower

## 📊 Model Evaluation

The model is evaluated using:

* Accuracy
* Confusion Matrix
* Precision
* Recall
* F1-Score
* Classification Report

## 🎯 Objective

The main objective is to understand the basic concepts of classification in Machine Learning and learn how to train, evaluate, and use a Machine Learning model for prediction.
